## 示例代码

示例代码位于另一个学习代码仓库：

```text
E:\Project\Golang-Start
```

在代码仓库根目录执行：

```powershell
go test ./...
```

运行某一个示例，例如：

```powershell
go run ./chapter-01-basics/examples/01-variables-constants
```

## 学习建议

阅读代码前先预测输出，运行后再修改变量和输入观察变化。练习题不直接提供答案，优先把每道题写成独立的 `main.go`，再用 `go test ./...` 检查整个项目。
